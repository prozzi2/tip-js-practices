| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |

| `Number("")` | Не записано | `0` | `number` | Пустая строка преобразуется в ноль. |

| `typeof NaN` | Не записано | `"number"` | `string` | NaN имеет числовой тип; результат typeof — строка. |
